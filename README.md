# NutriRecipe-Hub
#Goal
allow users organize their recipes, track daily meals, monitor their calories and nutritional intake all in one place. 

## Description
NutriRecipe Hub is a simple, responsive, web application designed to make meal and nutrition tracking easier. Users can browse and search for recipes, explore ingredients, and nutritional information, then add the meals to their daily food log. The app provides a clear overview of consumed and remaining calories, along with protein, carbohydrates, and fats, helping users stay aware of their daily nutritional intake. While supporting both languages English and Arabic.

## How to run the Project?
The application can be accessed directly through the deployed website:
NutriRecipe Hub: https://nutri-recipe-hub-copy-41116b54.base44.app

## How to use? 
1. Open the NutriRecipe Hub website.
2. Browse or search for recipes.
3. Select a recipe to view its ingredients, preparation steps, and nutritional information.
4. Click the + Add button to add a meal to the daily log.
5. Monitor your daily calories and macronutrients through the nutrition tracker.
6. Switch between Arabic and English using the language toggle. 

## Key features 
.Recipe browsing and search     
.Recipe categories     
.Ingredients and preparation instructions     
.Nutritional information for recipes    
.Daily meal logging    
.Calorie tracking    
.Protein, carbohydrate, and fat tracking    
.Daily calorie progress indicator
